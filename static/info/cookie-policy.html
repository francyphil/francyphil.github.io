Cookie Policy

Ultimo aggiornamento: 3 maggio 2026

1. Cosa sono i cookie e gli strumenti di storage

I cookie sono piccoli file di testo salvati sul dispositivo dell'utente dal browser durante la navigazione. Il localStorage è un meccanismo analogo, ma non trasmette dati al server a ogni richiesta: i dati rimangono nel browser dell'utente e vengono letti solo dal codice JavaScript della pagina.

2. Cosa usa questo sito

Il sito Annulli Meccanici è un sito statico. Non utilizza cookie di profilazione né cookie di tracciamento propri. Utilizza esclusivamente localStorage per ricordare la scelta di consenso dell'utente riguardo alle risorse di terze parti.

Hosting attuale: il sito è ospitato su GitHub Pages (GitHub Inc., USA).
Hosting futuro: il sito sarà migrato su un dominio personale ospitato da Aruba S.p.A. (Italia, server in Unione Europea). La presente policy verrà aggiornata contestualmente alla migrazione.

5. Cookie tecnici del servizio di hosting

Il servizio di hosting può impostare cookie tecnici strettamente necessari per il funzionamento dell'infrastruttura. Tali cookie non sono sotto il controllo del titolare di questo sito.

  • GitHub Pages (hosting attuale) — può impostare cookie tecnici di infrastruttura. I dati sono trattati da GitHub Inc. (USA) secondo la propria Privacy Policy.
  • Aruba S.p.A. (hosting futuro, server in Italia/UE) — potrà impostare cookie tecnici di infrastruttura. I dati resteranno all'interno dell'Unione Europea. Per i dettagli si rimanda all' Informativa Privacy Aruba.

6. Come gestire le preferenze

Puoi modificare la tua scelta in qualsiasi momento cliccando sul pulsante qui sotto. Il banner apparirà nuovamente e potrai accettare o rifiutare le risorse di terze parti.

Puoi inoltre eliminare i dati di localStorage dal tuo browser tramite le impostazioni dello strumento di sviluppo (F12 → Application → Local Storage) oppure cancellando i dati di navigazione del browser.
